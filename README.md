# Lektor TTS – userscript (Tampermonkey)

Skrypt Tampermonkey: lektor czytający napisy filmów (YouTube, Netflix i inne) przy użyciu lokalnych serwerów TTS:
Piper (8766), Supertonic (7000), XTTS (8000), Matcha PL (9000), OmniVoice (9100), Pocket PL (9200), Audio8 ONNX (9300).

Wersja: 4.2.13.0

## Instalacja
1. Zainstaluj rozszerzenie [Tampermonkey](https://www.tampermonkey.net/).
2. Otwórz plik `.user.js` z tego repozytorium (widok „Raw”) – Tampermonkey zaproponuje instalację.
3. Uruchom lokalnie wybrany serwer TTS na odpowiednim porcie.
